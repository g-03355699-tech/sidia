SiDIA

Maklumat sekolah

Maklumat ini dipaparkan di web app. Anda boleh mengubahnya bila-bila masa dalam tab TETAPAN.

Pengawas hanya boleh merekod dan melihat rekod sendiri. Admin (Guru Disiplin / PK HEM) membuka laporan, tetapan dan boleh menukar PIN dari web app (tab Admin). PIN boleh dibiarkan kosong jika web app hanya dibuka kepada akaun sekolah, tetapi PIN Admin sangat disyorkan.

Senarai murid

Muat naik fail Excel atau CSV. Boleh satu fail untuk semua murid, satu tab untuk setiap kelas, atau beberapa fail (satu fail setiap kelas).

📄
Klik untuk pilih fail atau seret fail ke sini
.xlsx, .xls, .csv, .ods · boleh pilih beberapa fail sekaligus
Lajur yang dikenal pasti: Nama (wajib), Kelas, Rumah / Rumah Sukan, No. MyKid / No. KP / ID. Jika tiada lajur kelas, nama tab atau nama fail digunakan sebagai kelas. Muat turun templat CSV

Kesalahan & mata demerit

Ubah mata, padam, atau tambah kesalahan mengikut peraturan sekolah. Tandakan ⭐ Pantas untuk kesalahan yang kerap direkod (cth solat, lewat) supaya dipaparkan paling atas di web app.

Salin jadual kesalahan dari Excel / Google Sheet (termasuk baris tajuk) dan tampal di sini. Lajur dikenal pasti: Kod/Code, Kesalahan/Description, Kategori/Category (1/2/3 atau Ringan/Sederhana/Berat), Mata/Demerit.

Aktifkan web app

Atas sebab keselamatan, Google memerlukan pemilik fail mengaktifkan web app sendiri. Langkah ini dibuat sekali sahaja dan mengambil masa kira-kira 1 minit.

  1. Buka Apps Script ↗ (tab baharu akan dibuka)
  2. Klik butang biru Deploy (kanan atas) › New deployment.
  3. Klik ikon ⚙ di sebelah Select type › pilih Web app.
  4. Execute as: Me
    Who has access:
  5. Klik Deploy. Jika diminta, klik Authorize access › pilih akaun › Allow.
  6. Kembali ke tetingkap ini dan klik Semak di bawah.
atau tampal Web app URL:
